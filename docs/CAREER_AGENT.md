# Career Intelligence Agent

## Goal
Discover relevant engineering vacancies, explain match quality, prepare truthful CV variants and approval-ready applications. Never invent experience or submit without owner approval.

## Profile
Versioned, owner-confirmed professional profile: verified roles, technologies, achievements, locations, work authorization, languages, target titles, compensation and remote/hybrid preferences. Initial title candidates: Staff Backend Engineer, Principal Engineer, Backend Tech Lead, Solution Architect. Do not assume unconfirmed preferences.

## Discovery
Use LinkedIn job-alert emails and permitted job-board feeds/APIs and employer career pages. Deduplicate by employer, role, location and job ID. Preserve original posting URL, posting date, requirements and published compensation.

## Scoring
Configurable explainable 0–100 rubric: seniority 25, technical/domain fit 25, location/remote 20, responsibilities 15, compensation 10, other 5. Hard exclusions override the score. Store evidence, missing data and owner feedback.

## CV and applications
Immutable master CV, verified achievements only, job-specific PDF/DOCX variants, cover letters, application-question drafts. Workflow: discovered -> shortlisted -> prepared -> awaiting approval -> submitted -> follow-up -> closed. Approval must cover employer, job URL, exact CV, recipient and answers. If direct authorized submission is unavailable, produce a manual submission packet.

## LinkedIn social
Track relevant posts through permitted feeds, alerts and sources; summarize importance, draft professional comments and request approval before posting.

## Tests
Duplicate jobs, hard exclusions, CV hallucination rejection, application replay rejection, altered payload rejection, expired approvals, provider failures and manual submission fallback.
