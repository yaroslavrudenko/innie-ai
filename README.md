# Innie AI

Personal AI assistant built on Claude Agent SDK. Hybrid architecture: MacBook primary worker, optional cloud monitoring and encrypted off-site backup.

## Status

**Specification / implementation handoff only.** The working application and infrastructure have not yet been implemented or deployed.

Read [Implementation specification](docs/IMPLEMENTATION_SPEC.md) and [Claude Code instructions](CLAUDE.md).

## Start development

1. Review the security gates and manual OAuth checkpoints in the specification.
2. Open this repository in Claude Code.
3. Ask Claude Code to implement phases A–F and run the acceptance tests.
4. Keep `ALLOW_SEND=false` until explicitly approved.
